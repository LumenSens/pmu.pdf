# 00 — État du projet

Date : 13/09/2026

## Décision

Nova PMU est relancé comme **programme de recherche**, pas comme stratégie de pari validée.

Thèse active : **COURSE → MARCHÉ → CHEVAUX → DÉCISION**.

Nova cherche des situations où le marché peut être mal évalué, puis tente de réfuter chaque signal.

## Actifs présents dans GitHub

- archives Nova 1 à 4 ;
- synthèse Nova 5.0 (2025) ;
- synthèse historique un an ;
- tableur autostart et documentation trot.

## Actifs absents au 13/09/2026

- base exacte des 24 973 courses annoncées ;
- scripts V6/V12 et branches A à D ;
- sorties brutes et configurations ;
- environnement Python verrouillé ;
- historique horodaté des cotes ;
- ferrure consolidée.

Les résultats anciens sont donc **rapportés/non reproduits**.

## Décisions verrouillées

- aucune Nova 6 monolithique avant audit ;
- aucun ROI global ne suffit à valider une idée ;
- archives et méthode active restent séparées ;
- aucune simulation intraday à partir d'une seule cote finale ;
- aucun pari réel avant test prospectif papier ;
- données brutes immuables, transformations codées ;
- un résultat négatif documenté reste utile.

**Verdict : relance autorisée ; méthode de pari non validée.**
